# Tài Liệu Guide

Thư mục này chứa tài liệu hướng dẫn triển khai chi tiết theo hướng runbook.

Phạm vi chính:
- Thiết lập môi trường, cấu hình và vận hành.
- Luồng thao tác theo từng bước cho dev/test.
- Hướng dẫn kiểm thử nhanh, kiểm thử tích hợp và xử lý sự cố.
- Đối chiếu giữa tài liệu và mã nguồn để triển khai đúng vị trí.

Nguyên tắc biên soạn:
- Ưu tiên tính thực thi: đọc xong có thể làm ngay.
- Trình bày theo thứ tự thao tác, hạn chế mô tả lý thuyết dài.
- Mọi biến cấu hình/điểm vào kỹ thuật phải nêu rõ file và module liên quan.

Tài liệu trong thư mục này trả lời câu hỏi: "Làm như thế nào?"
